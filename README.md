# 🐾 Pet Store – Full Stack E-Commerce Web App

A full-stack Pet Store web application built using Django and Python that allows users to browse pets, manage carts, authenticate accounts, and experience a responsive online shopping interface.

The application includes product categories, authentication, cart functionality, checkout flow, and dynamic product pages with a clean user experience.

---

## 🚀 Features
* 🔐 User Authentication (Login / Signup)
* 🐶 Browse Different Pet Categories
* 🛒 Shopping Cart Functionality
* 💳 Checkout / Payment Page
* 📦 Dynamic Product Pages
* 📱 Responsive User Interface
* 🖼️ Static Media & Image Handling
* ⚡ Django Template Rendering

---

## 🧠 How It Works

1. Users browse pets and categories
2. Add products to cart
3. Create account or login
4. Proceed to checkout/payment page
5. Django handles backend routing, templates, and product management

The application follows the Django MVC/MVT architecture using templates, views, models, and static assets.

## ⚙️ Installation & Setup

### 1️⃣ Clone the repository

```
git clone https://github.com/gautampoojari/Pet-Store.git
cd Pet-Store
```

### 2️⃣ Create Virtual Environment

```
python -m venv venv
```
Activate virtual environment:
* Windows
```
venv\Scripts\activate

```
* Mac/Linux
```
source venv/bin/activate

```

### 3️⃣ Install Dependencies

```
pip install django
```

### 4️⃣ Run Server
```
python manage.py runserver

```
* Open in browser:
```
http://127.0.0.1:8000/

```
